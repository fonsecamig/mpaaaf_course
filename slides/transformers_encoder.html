Motivation

Motivation

We want to learn representations of sequential data that:

  • capture long-range dependencies
  • integrate multiple signals simultaneously
  • adapt to context dynamically

Challenges:

  • Financial time series are noisy and non-stationary
  • NLP data is highly context-dependent
  • Classical models struggle to combine global context + multiple features

Transformer encoders provide a unified solution:

  • global context via attention
  • flexible representation learning
  • scalable training

Encoder Role

TensorFlow 2: Encoder Block

import tensorflow as tf
from tensorflow.keras import layers

class TransformerEncoder(layers.Layer):
    def __init__(self, d_model, num_heads, dff):
        super().__init__()
        self.att = layers.MultiHeadAttention(num_heads, d_model)
        self.ffn = tf.keras.Sequential([
            layers.Dense(dff, activation='relu'),
            layers.Dense(d_model)
        ])
        self.norm1 = layers.LayerNormalization()
        self.norm2 = layers.LayerNormalization()

    def call(self, x):
        attn = self.att(x, x)
        x = self.norm1(x + attn)
        ffn = self.ffn(x)
        return self.norm2(x + ffn)

Stacking Encoders

class EncoderStack(tf.keras.layers.Layer):
    def __init__(self, num_layers, d_model, num_heads, dff):
        super().__init__()
        self.layers_ = [
            TransformerEncoder(d_model, num_heads, dff)
            for _ in range(num_layers)
        ]

    def call(self, x):
        for layer in self.layers_:
            x = layer(x)
        return x
